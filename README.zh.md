## 为什么要用这种方式？（而不是 Electron 桌面应用）

很多工具把 Web 界面"应用化"时习惯用 **Electron** 包装（打包一个完整的 Chromium + Node.js 运行时）。但对 DeepSeek Harness 这类**本来就是本地服务 + 浏览器界面**的工具，Electron 是杀鸡用牛刀：

| 对比项 | Electron 包装 | 本方案（PWA + 启动器） |
|---|---|---|
| **额外内存** | 每个应用常驻一个完整的 Chromium 实例，空闲也占 **几百 MB** | 复用你**本来就在用的浏览器**，额外内存**接近于零** |
| **磁盘占用** | 每个应用几百 MB（自带运行时） | 只有两个脚本 + 一个图标，**KB 级** |
| **安装负担** | 需要下载安装器、升级要重装 | 浏览器「安装为应用」一步完成，升级即浏览器升级 |
| **后台常驻** | 应用进程常驻，关窗口也可能残留 | 关窗口 = 关界面；服务进程可控（Ctrl+C / 关窗口） |
| **与现有环境** | 自带一套隔离运行时，与系统脱节 | 直接用系统浏览器，外观/字体/代理/证书与日常一致 |

**核心思路**：DeepSeek Harness 的服务本来就跑在本地（`http://127.0.0.1:3080`），浏览器只是它的"显示器"。与其再包一层重量级运行时，不如让**已经在用的浏览器**来当这个显示器 —— 双击图标自动拉起本地服务、打开 PWA 窗口，体验上和原生应用无异，资源占用却轻得多。

## 0. 前置要求：安装 Node.js（必须）

`npx` 随 Node.js 一起安装，**没有 Node.js 脚本无法运行**。

> 平台说明：本方案的脚本（`launch-dsh.ps1` / `launch-dsh.vbs`）与 PWA 安装步骤**暂时只在 Windows 上验证过**；macOS / Linux 上的行为未经测试，如有需要请自行验证（例如 macOS 上可直接用 `npx -y @deepseek-ai/dsh web` 启动服务，但一键启动脚本尚未适配）。

1. 打开 <https://nodejs.org/>，下载 **LTS 版本**（如 v22 LTS），一路下一步安装。
2. 安装完成后**重新打开**终端/资源管理器（让 PATH 生效），验证：

   ```cmd
   node -v
   npm -v
   ```

   两个命令都能打印版本号即成功。

## 1. 两种启动服务的方式

### 方式 A：命令行手动启动（临时用）

```cmd
npx -y @deepseek-ai/dsh web
```

- 首次运行会从 npm 下载 `@deepseek-ai/dsh` 包（需要联网，约几十 MB），之后走缓存秒开。
- 服务启动后终端会显示地址（默认 `http://127.0.0.1:3080`）。
- 停止：在该终端按 `Ctrl+C`。

### 方式 B：双击图标一键启动（推荐，配合桌面快捷方式）

见第 3 节，把桌面图标指向 `launch-dsh.vbs`，之后双击图标 = 自动启动服务 + 自动打开界面。

---

## 2. 把网页界面安装为浏览器应用（PWA）

安装后会在桌面/开始菜单生成一个"应用图标"，点击它就像打开一个独立桌面程序。

### Edge（推荐）

1. 先按第 1 节把服务跑起来，浏览器打开 `http://127.0.0.1:3080/`。
2. 点浏览器右上角 **⋯（设置及更多）** → **应用** → **将此站点作为应用安装**。
3. 弹窗里点 **安装**。安装完成后会自动打开应用窗口，**桌面会自动出现快捷方式**。

### Chrome

1. 打开 `http://127.0.0.1:3080/`。
2. 地址栏右侧若有安装图标（显示器带 + 号）直接点它；没有则点菜单 **⋯** → **保存并分享** → **创建快捷方式…**。
3. 勾选 **在窗口中打开**，点 **创建**。桌面同样会生成快捷方式。

> 注意：这个快捷方式**只是打开页面的窗口**，不会自动启动服务。要"双击即用"，继续看第 3 节。

---

## 3. 把桌面快捷方式改成"一键启动"

原理：把快捷方式的目标从"打开网址"改成"运行 `launch-dsh.vbs`"。双击图标时脚本会：探测服务 → 没跑就后台启动（可见控制台窗口）→ 等 HTTP 就绪 → 打开界面。

### 步骤

1. 把本文件夹放到一个固定位置（例如 `C:\Users\<你的用户名>\dsh-pwa-setup\`），**不要随意移动**。
2. 桌面找到上一步生成的快捷方式（如「DeepSeek Harness」）→ 右键 → **属性** → **快捷方式** 选项卡。
3. 在 **目标** 一栏填入（引号保留，路径按你的实际位置改）：

   ```cmd
   wscript.exe "C:\Users\<你的用户名>\dsh-pwa-setup\launch-dsh.vbs"
   ```

4. （可选）**更改图标**：点「更改图标」→ 浏览 → 选本套件里的 `DeepSeek Harness.ico`（已从 Edge 应用备份过来），或任意你喜欢的图标。
5. 点 **确定**。现在双击图标即可一键启动。

### 停止服务

在启动时弹出的「DeepSeek Harness 服务」控制台窗口里按 `Ctrl+C`，或直接关闭该窗口。

## 4. 脚本说明

### launch-dsh.ps1（核心逻辑）

- 就绪判断：用 HTTP 请求轮询 `http://127.0.0.1:3080/`，**拿到 200 响应才打开浏览器**，避免"地址无法连接"。
- 服务启动命令：`npx -y @deepseek-ai/dsh web`（工作目录取当前用户主目录）。
- 等待上限 90 秒（首次下载 npx 包较慢），超时弹窗提示。
- **Edge 定位**：优先读注册表 `App Paths\msedge.exe`，其次常见安装路径 —— 即使 Edge 装在自定义目录也能找到；找不到 Edge 或没装 PWA 时自动退回默认浏览器。
- 界面打开方式：优先 Edge PWA 应用窗口（若检测到本机安装过），否则用默认浏览器。

### launch-dsh.vbs（无黑框包装器）

- 用 `wscript.exe`（无控制台窗口）隐藏启动 PowerShell，双击时不会闪现黑框。
- 自动读取**自身所在目录**下的 `launch-dsh.ps1`，所以两个文件必须放在同一文件夹。

## 5. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击无反应 | 没装 Node.js（见第 0 节），或脚本路径含引号错误 |
| 弹「服务启动似乎失败了」 | 看「DeepSeek Harness 服务」窗口里的报错；首次 npx 下载慢可稍等再双击 |
| 提示 `npx 不是内部或外部命令` | Node.js 未安装或 PATH 未生效，重装后重新开终端 |
| 服务一直在跑但图标打不开 | 端口被占用？用 `netstat -ano | findstr :3080` 查看 |
| Edge 重新安装应用后图标失效 | Edge 重新生成了快捷方式，把目标改回 `wscript.exe "…\launch-dsh.vbs"` 即可 |

---

## 6. 还原默认

想恢复成"只开窗口、不启服务"：把快捷方式目标改回原来的 Edge 应用地址（属性里能看到），或直接删除快捷方式后在 Edge 应用页重新固定。
